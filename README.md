# 色季衣橱

一个帮助用户在网购时判断服装颜色是否适合个人四季型的网页原型。

## 当前功能

- 上传服装商品图片
- 点击衣服区域，手动确认要分析的颜色
- 选择 12 季型与穿着场景
- 输出颜色名称、相近季型、个人适配参考、风格标签与搭配建议

## 使用方式

直接打开 `index.html`，上传一张商品图片后，点击衣服主体的颜色即可开始分析。

## 说明

当前结果基于图片取色和内置参考色板，适合作为购物决策参考；商品滤镜、光线和屏幕显示可能影响识别结果。
